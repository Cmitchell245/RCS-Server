# RCS-Server
Building an IT infrastructure home lab to simulate a small business environment using OPNsense, a TP-Link managed switch, a Windows 11 Pro workstation, a Windows Server system, and a PlayStation 5. This project focuses on VLANs, IPv4 subnetting, firewall configuration, inter VLAN routing, Active Directory, DNS, Group Policy, and technical documentation. The goal is to develop hands on experience with enterprise networking and systems administration while preparing for the CompTIA Network+ and Cisco CCNA certifications.

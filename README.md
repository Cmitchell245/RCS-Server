# RCS-Server

## Overview

Building an IT infrastructure home lab to simulate a small business environment using OPNsense, a TP-Link managed switch, a Windows 11 Pro workstation, a Windows Server system, and a PlayStation 5.

## Project Focus

This project focuses on:

- VLAN configuration
- IPv4 subnetting
- Firewall configuration
- Inter VLAN routing
- Active Directory
- DNS
- Group Policy
- Technical documentation

## Goal

The goal of this project is to develop hands on experience with enterprise networking and systems administration while preparing for the CompTIA Network+ and Cisco CCNA certifications.
